# Nine-Tailed Fire Fox — Blender 5.2 generator + Roblox boss asset

A colossal, snarling fire-fox beast: a hulking grey wolf-like body on four legs, a heavy head
with saber fangs and glowing slit-pupil eyes, ears pinned back with torn notches and black tufts,
a mane of flames over the neck and shoulders, and nine huge flame tails fanned out behind it. About **12 studs tall** in Roblox (ground to ear tips; the
tails tower above that).

Everything is generated by one script, `desert_fox.py`, with stock **Blender 5.2 LTS** — no
add-ons, no external files.

| Version | What it is | Use it for |
| --- | --- | --- |
| **HQ / cinematic** | one continuous sculpted body, ~130k–550k hair strands, sculpted flame tongues (tails, mane, paws) with glowing gradient fire, layered eyes, 32 teeth, tongue, claws | Blender renders, promo art, reference |
| **Roblox** | body mesh (~12k tris, baked colour/normal/roughness) + separate flame mesh (~10k tris, fire-gradient texture) + 51-bone rig, one FBX | the game |

**Final build (medium quality, Blender 5.2.2 LTS, 4-core CPU):** 313,099 fur strands,
403,716-triangle body (render subdivision), 14 flame groups, creature scale ×6.38 →
3.36 m / 12.0 studs tall. Roblox: body 13,302 tris + flames 9,984 tris, 51 bones,
size 5.4 × 15.2 × 12.0 studs (w × l × h, body). Build + Roblox bake ≈ 10 min, each
1600×1200 render ≈ 4–7 min on CPU.


## 1. Run the script

**In Blender 5.2 (GUI)**

1. Start Blender 5.2 and choose **File → New → General** (the script refuses to wipe a file that
   has your own work in it).
2. Go to the **Scripting** workspace → **Text → Open…** → `desert_fox.py`.
3. Optional: edit the `SETTINGS` block at the top (`quality`, `render`, `out_dir`).
4. Press **Run Script**. A progress bar shows in the status bar; details print to the system
   console (Windows: **Window → Toggle System Console**). It takes several minutes at `medium`
   — the Roblox texture bake is the slowest step.
5. Output (default `~/DesertFox_Output`, i.e. `C:\Users\<you>\DesertFox_Output` on Windows):
   `DesertFox.blend`, `roblox/…`, and `renders/…` if rendering was on.

**Headless**

```bash
blender --background --python-exit-code 1 --python desert_fox.py -- --quality high --render
```

Options after `--`: `--quality draft|medium|high`, `--render`, `--views front_3q,face_closeup`,
`--no-roblox`, `--out <folder>`.

| Quality | Fur strands (approx.) | Mesh voxel* | Samples | Resolution |
| --- | --- | --- | --- | --- |
| draft | ~130k | 2.4 mm | 24 | 960×720 |
| medium | ~320k | 1.7 mm | 64 | 1600×1200 |
| high | ~580k | 1.3 mm | 128 | 2048×1536 |

\*measured on the model before the creature scale (×6.4) is applied.

## 2. How it is built

* **Anatomy** — a signed-distance-field sculpt meshed by a built-in surface-nets mesher:
  barrel ribcage, deep chest and pectorals, hunched trapezius hump, massive scapulae and
  deltoids, lats, bull neck, big haunches; broad cranium, heavy brow ridge with a frowning
  inner brow, cheekbones, muzzle with snarl folds, lips pulled back from the fangs, a separate
  lower jaw opened 22°, carved mouth cavity, almond eye openings slanted 22°; thick digitigrade
  legs with elbow/hock points and muscle masses, oversized paws with four toes each.
* **Pose** — neck lowered 16°, head lifted 13° into a glare and enlarged ×1.22, jaw open.
* **Flames** — procedural "flame tongues": leaf-shaped, lens-section ribbons that curl one way
  and flick back near the tip (the S-shape of sculpted fire), with a sideways wave. Colour runs
  grey (fur roots) → deep magenta → hot pink → orange → amber → yellow-hot tips; the tips glow
  (emission). Nine tails = fat core flame + ~15 wide tongues hugging it and curling off; the
  mane = ~42 layered tongues sweeping back from the neck, shoulders and throat; plus flames rising from
  the coat.
* **Fur** — Blender hair curves on the body: underfur + guard hairs, direction from an anatomical
  flow skeleton, bristling hackles and spiky dorsal crest (clumped), charcoal-grey colouring
  with a darker saddle and face mask, black stockings and paws.
* **Details** — eyeball with procedural amber iris + slit pupil + glow, glass cornea, eyelid
  rims, wet nose with nostrils, 32 teeth (saber canines), tongue, gums, 16 hooked claws, paw pads,
  thick cupped ears with torn notches, inner fringe and black tip tufts.

## 3. Render setup

* Cycles, adaptive sampling, OpenImageDenoise.
* **Colour management: Standard** (AgX/Filmic turn the saturated fire pastel).
* Hair shape: 3D curves (`Render Properties → Curves`) at medium/high.
* Low-key studio: dark cyclorama, warm hard key, cool low fill, two hot orange rim lights; the
  flames add their own glow. All lights and cameras scale with the creature.
* Cameras: `Cam_front_3q`, `Cam_side`, `Cam_front`, `Cam_rear_3q`, `Cam_face_closeup` (105 mm,
  shallow depth of field on the eyes).
* CPU rendering is slow with this much hair; a GPU (Preferences → System → Cycles Render Devices)
  is much faster. For a hero shot use `--quality high` and raise samples to 256.

## 4. Roblox asset

Folder `roblox/`:

| File | What |
| --- | --- |
| `DesertFox_Roblox.fbx` | armature + `Fox_Roblox` (body) + `Fox_Flames` (all fire), colour textures embedded |
| `FoxRoblox_Color.png` / `_Normal.png` / `_Roughness.png` | 1024 px body maps (normal map is OpenGL / +Y) |
| `FoxRoblox_Fire.png` | the fire gradient used by the flame mesh |

* **Body mesh**: the skin pushed out by the local fur length (so the outline stays furry, with
  big tufts and crest spikes), voxel-remeshed, decimated, plus low-poly ears, eyes, nose, teeth
  and tongue; smart-unwrapped on a smoothed copy and packed; colour/normal/roughness baked from
  the detailed sources (fur grooves follow the hair direction in the normal map).
* **Flame mesh**: low-poly versions of the same flame tongues, UV-mapped onto the gradient.
* **Rig (51 bones)**: `Root → Hips → Spine1 → Spine2 → Chest → Neck → Head → Jaw`,
  `Ear.L/R → EarTip.L/R`, `FrontUpperLeg / FrontLowerLeg / FrontFoot .L/.R`,
  `BackUpperLeg / BackLowerLeg / BackFoot .L/.R`, and `FireTail1_1…_3` … `FireTail9_1…_3`
  (three per tail). Skin weights: max 4 influences, jaw/ears/head/legs separated cleanly
  (checked by posing every bone).
* Export: 1 Blender unit = 1 stud (scene unit scale 0.01 + *FBX Units Scale*), −Z forward,
  +Y up, triangulated before baking, no leaf bones, no animation.

## 5. Import into Roblox Studio

1. **Home → Import 3D** → `DesertFox_Roblox.fbx`.
2. Keep it as a **skinned model with bones** (do not convert to R15). Check the preview: it faces
   forward and stands on the grid, about 12 studs to the ear tips. Change the importer scale or
   use `Model:ScaleTo()` if you want it bigger or smaller.
3. You get a Model with two MeshParts (`Fox_Roblox`, `Fox_Flames`) and the bones.
4. **Body textures**: add a **SurfaceAppearance** to `Fox_Roblox` with ColorMap =
   `FoxRoblox_Color.png`, NormalMap = `FoxRoblox_Normal.png`, RoughnessMap =
   `FoxRoblox_Roughness.png`.
5. **Fire**: `Fox_Flames` already shows the pink→yellow gradient. For a real glow, either set its
   `Material = Neon` (one colour, e.g. hot pink), or keep the texture and add a few
   `PointLight`s (orange/pink, Range 10–16) inside the mane and tails. A `ParticleEmitter` with
   embers on the tails sells it further.
6. **Eyes**: add a small orange `PointLight` in the head (or neon parts) — Roblox has no emissive
   texture slot.
7. Animate with the **Animation Editor** (bones are supported): walk, pounce, roar (Jaw), ear
   flicks, and swishing each of the nine tails.
8. Gameplay: give the boss its own invisible hitbox Part; set the MeshParts'
   `CollisionFidelity = Box` (or `CanCollide = false`).

Not transferable to Roblox: hair strands, the refractive cornea, procedural shader nodes and
emission — the game version imitates them with geometry, baked textures and the gradient.

## 6. Quality checklist

Measured on the final build; the Roblox checks were done by re-importing the exported FBX.

| Check | Result |
| --- | --- |
| Anatomy | Continuous SDF body; validation passed; all four paws flat on the ground (636 / 795 / 812 / 697 contact vertices) |
| Fur coverage | 313,099 strands at medium (underfur + guard + ear fringes/tufts); no fur on eyes, nose, lips or inside the mouth |
| Eyes | Separate eyeball (amber iris, radial fibres, limbal ring, slit pupil, glow), glass cornea (no shadow), eyelid rims, almond opening slanted 22° |
| Ears | Thick cupped pinnae with forward-curling rims, torn notches (asymmetric), dark matte inner skin, pale rim fringe, black tip tufts |
| Tails | Nine flame tails, fat cores + wide curling flame tongues; grey roots blending into pink → orange → yellow tips |
| Mesh integrity | HQ body 1 non-manifold edge in 84k faces (draft); Roblox body voxel-remeshed (manifold) before decimation; right-side teeth winding verified |
| UVs | Smart UV on a smoothed copy + packed islands (no thousand-island shatter); flames UV-mapped onto a gradient strip |
| Materials | Principled Hair BSDF fur, emissive gradient fire, wet nose, refractive cornea, ivory teeth; Standard view transform keeps the fire saturated |
| Polygon budget | Roblox body 13,302 tris, flames 9,984 tris (Roblox limit 20,000 per MeshPart) |
| Rigging | 51 bones, no leaf bones; every vertex ≤ 4 influences, weights sum to 1.000; posing tests: Jaw moves only the jaw (both sides evenly), Ear.L only the left ear, each FireTail bone only flame vertices, FrontUpperLeg.L only its own side, Head moves skull + ears + eyes + teeth together |
| Export orientation | −Z forward, +Y up, triangulated, textures embedded (Color, Normal, Roughness, Fire) |
| Roblox import | Units: 1 Blender unit = 1 stud (unit scale 0.01, FBX Units Scale), so the model comes in ~12 studs tall. **Not test-imported in Roblox Studio** (not available here) — check the importer preview size and facing on first import |
