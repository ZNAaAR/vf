# Desert Fox Boss — Blender 5.2 generator + Roblox asset

A giant, snarling fantasy desert fox (big-eared Rüppell's / bat-eared fox type, pushed into a
boss creature): about 4× the size of a real fox, with glowing slit-pupil eyes, saber fangs,
ears pinned back with torn notches, a bristling spiky crest and mane, black "stockings", hooked
claws and a huge black-tipped tail.

Everything is generated by one script, `desert_fox.py`. It needs nothing beyond stock Blender
**5.2 LTS** and no add-ons. It builds two things:

| Version | What it is | Use it for |
| --- | --- | --- |
| **HQ / cinematic** | one continuous sculpted body, ~250k–500k real hair strands (underfur + guard hairs + clumped spikes), layered eyes, individual teeth, tongue, claws, pads | Blender renders, promo shots, reference |
| **Roblox** | ~15k-triangle mesh that keeps the fur *silhouette*, 1024 px baked colour / normal / roughness maps, 29-bone skinned rig, FBX | the game |

## 1. Run the script (Deliverable 2)

**In Blender 5.2 (GUI)**

1. Open Blender 5.2, go to the **Scripting** workspace.
2. **Text → Open…** → `desert_fox.py`.
3. Optional: edit the `SETTINGS` block at the top (`quality`, `render`, `out_dir`).
4. Press **Run Script**. Blender will look frozen while it works (about 5–10 min at `medium`; the
   Roblox bake is the slowest part). Watch progress in the system console
   (**Window → Toggle System Console** on Windows).
5. The script saves `DesertFox.blend` in the output folder (default
   `~/DesertFox_Output`, i.e. `C:\Users\<you>\DesertFox_Output` on Windows) and opens it.

> The script **builds into a fresh, empty file** — it does not touch your other work, but anything
> unsaved in the currently open file is discarded, so save first.

**Headless (faster, no UI)**

```bash
blender --background --python desert_fox.py -- --quality high --render
```

Options after `--`: `--quality draft|medium|high`, `--render`, `--views front_3q,face_closeup`,
`--no-roblox`, `--out <folder>`.

| Quality | Fur strands (approx.) | Mesh voxel | Samples | Resolution |
| --- | --- | --- | --- | --- |
| draft | ~125k | 2.4 mm | 24 | 960×720 |
| medium | ~300k | 1.7 mm | 64 | 1600×1200 |
| high | ~550k | 1.3 mm | 128 | 2048×1536 |

(Measurements are for the real-fox-sized build before the 4× creature scale is applied.)

## 2. How it is built

* **Anatomy** — a signed-distance-field "sculpt": ribcage, deep chest, withers hump, scapulae,
  haunches, thick neck, cranium, brow ridges + frowning inner brow, zygomatic arches, muzzle,
  snout, separate lower jaw (opened 22°), snarl folds across the muzzle, lips pulled back from the
  fangs, almond eye openings slanted 22°, carved mouth cavity, digitigrade legs with
  elbow/hock points and muscle masses, paws with four toes and flat ground contact. Everything is
  blended with smooth unions and meshed by a built-in surface-nets mesher (no plug-ins).
* **Pose** — neck lowered 16°, head lifted 13° so the eyes glare forward; jaw open.
* **Parts** — cupped, thick-rimmed ears with torn notches; eyeball with procedural amber iris,
  radial fibres, limbal ring and vertical slit pupil (emissive glow); glass cornea; eyelid rims;
  nose with nostrils, philtrum groove and pebbled bump; 32 individual teeth; tongue; 16 claws;
  paw pads; separate tail object.
* **Fur** — Blender hair curves. Hair direction follows an anatomical flow skeleton (back from
  the nose, down the chest, along the limbs, radiating down the tail), with region-specific
  length, lift (how much it stands up — the hackles and crest bristle), clumping into spikes,
  frizz, gravity. Short dense underfur + longer guard hairs with dark tips. Colour comes from
  anatomical masks + noise (dark saddle and crest, face mask, cream cheeks/jaw, rust chest,
  black stockings and paws). Ears get pale inner fringes, short outer fur and black tip tufts.
* **Materials** — Principled Hair BSDF (direct colouring, root darkening, tip colour), skin under
  the fur, translucent ears, wet nose (coat + Voronoi bump), iris + emissive glow, refractive
  cornea, ivory teeth, tongue, claws, pads.

## 3. Render setup (Deliverable 3)

* Cycles, CPU or GPU, adaptive sampling, OpenImageDenoise, AgX view transform
  (Medium High Contrast look).
* Hair: `Render Properties → Curves → Shape: 3D Curves` (Thick) at medium/high.
* Lights (all area lights, scaled with the creature): warm hard **key** front-left, cool low
  **fill**, two hot desert-orange **rim** lights behind to light up the fur edges; dark warm-grey
  cyclorama and a dim world.
* Cameras: `Cam_front_3q`, `Cam_side`, `Cam_front`, `Cam_rear_3q`, `Cam_face_closeup`
  (105 mm, shallow depth of field on the eyes).
* For final images use `--quality high` (or set samples 256 for the close-up). On a 4-core CPU a
  1600×1200 frame takes several minutes; a GPU is much faster
  (Edit → Preferences → System → Cycles Render Devices).

## 4. Roblox asset (Deliverable 4)

Output folder `roblox/`:

* `DesertFox_Roblox.fbx` — mesh + armature, colour texture embedded.
* `FoxRoblox_Color.png`, `FoxRoblox_Normal.png` (OpenGL / +Y), `FoxRoblox_Roughness.png` — 1024 px.

What the script does: builds a "fur hull" mesh (skin pushed out by the local fur length, with
tufts and spikes so the outline still looks furry), voxel-remeshes and decimates it, adds low-poly
ears, eyes, nose, teeth and tongue, UV-unwraps, bakes colour/normal/roughness from the detailed
sources, builds the rig, skins it (max 4 influences per vertex), triangulates and exports FBX with
1 Blender unit = 1 stud (scene unit scale 0.01, *FBX Units Scale*), −Z forward, +Y up, no leaf
bones, no animation.

**Rig** (29 bones): `Root → Hips → Spine1 → Spine2 → Chest → Neck → Head → Jaw`,
`Ear.L/R → EarTip.L/R`, `FrontUpperLeg / FrontLowerLeg / FrontFoot .L/.R`,
`BackUpperLeg / BackLowerLeg / BackFoot .L/.R`, `Tail1 … Tail5`. Enough to walk, run, idle,
turn the head, snap the jaw, flick the ears and swish the tail.

## 5. Import into Roblox Studio (Deliverable 5)

1. **Home → Import 3D** (or File → Import 3D) → choose `DesertFox_Roblox.fbx`.
2. In the importer: *Rig General → Rig Type*: keep it as a **skinned mesh with bones**
   (do not convert to R15). Check the preview: it should face forward and stand on the grid.
   If the size is not what you want, change *Scale Unit* / *World scale* there, or after import
   use `Model:ScaleTo()`.
3. Import. You get a Model containing the MeshPart with Bones.
4. Textures: the colour map is usually applied automatically. For the full look, insert a
   **SurfaceAppearance** into the MeshPart and upload `FoxRoblox_Color.png` → ColorMap,
   `FoxRoblox_Normal.png` → NormalMap, `FoxRoblox_Roughness.png` → RoughnessMap.
5. Animate with the **Animation Editor** (it supports bones), or move bones from scripts
   (`Bone.Transform`). Anchor the root part or add a `Humanoid`/`AnimationController` as your
   game needs.
6. For a boss, add your own hitbox (an invisible Part) — don't use the detailed mesh for
   collisions (`CollisionFidelity = Box` on the MeshPart).

What does not transfer to Roblox: Blender hair strands, the refractive cornea, procedural shader
nodes and the eye glow shader. The game mesh imitates them with geometry, baked textures and
roughness. To keep the glowing eyes in-game, add a small `PointLight` (orange, Range ≈ 4) in the
head, or neon parts at the eyes.
